# README conversation images

These are synthetic sample conversations, not user conversations or photos of the physical glasses.

Captured using the official Even Hub Simulator 0.9.5 with the public Dot Link source at 42332b7 (Even app 0.2.27). The screenshot API’s transparent glasses image is displayed on a black background and captured at 576 × 288 CSS pixels. No status indicators or conversation text were added to the captured image afterward.

The simulator does not fully reproduce status indicators on physical G2 glasses. These images illustrate the conversation layout only and do not establish physical-device behavior or the public availability of the captured build.

English and Japanese use the same fictional conversation about taking a walk and visiting a cafe. Network responses are local fixtures; no Dot account, personal relay, microphone, location or private conversation is used.
