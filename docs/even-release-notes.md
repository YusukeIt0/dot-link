# Even app release notes

Version history describes app changes. Check Even Hub for the version currently available to you.

## 0.3.42

- Clarified how nearby map data is kept on your Mac when location sharing is enabled.
- Use with Dot Link for Mac 0.4.23 or later for automatic geographic references alongside shared coordinates.

## 0.3.41

- Updated the phone send button to a paper-plane icon matching the camera and photo controls.

## 0.3.39

- Added camera and photo-library attachments, with previews and removal before sending.
- Added up to four photos per message, with optional typed or dictated text.
- Photo messages follow your automatic speech sending setting; selecting a photo alone never sends it.
- Prevented adding the same photo more than once to a message.

## 0.3.36

- Added Traditional Chinese, Simplified Chinese, French and German to the phone interface and glasses status messages, with automatic language selection.
- Read-aloud now turns off when you change the interface language.

## 0.3.33

- Added Korean to the phone interface and glasses status messages, including automatic selection on Korean-language phones.
- Improved removal of a recognized Hey Dot cue from Korean transcriptions.

## 0.3.31

- Updated app components to address security vulnerabilities.

## 0.3.29

- Moved Revoke this device to the bottom of the Mac connection section.
- Fixed disconnect to stop this device immediately and remember the removal request when the Mac is offline.
- Added automatic retries for pending Mac removal after reopening the app.
- Clarified when Mac removal is pending or disconnect settings could not be saved.
- Update Dot Link for Mac to 0.4.14 or later for reliable removal retries.

## 0.3.25

- Improved the phone message field to grow from one to five lines as you type or dictate, then scroll for longer messages.

## 0.3.23

- Improved phone conversation controls with a rounded message field, history arrows and a read-aloud toggle.
- Improved recording controls with a microphone icon that changes when recording and an adjacent trash icon to discard speech.

## 0.3.21

- Improved connection recovery when reopening the app, without pairing again.
- Reduced brief reconnect indicators while keeping sustained connection failures visible.
- Improved background reconnection after network interruptions.
- Use with Mac 0.4.10 or later for the full connection-recovery improvements.

## 0.3.19

- Added **Disable hold-to-record** to prevent accidental recording from glasses controls or the phone button.
- Kept Hey voice activation and text input available when manual recording is disabled.
- Remembered the setting after reopening the app.

## 0.3.17

- Clarified how to remove connections on the Mac when this phone cannot confirm disconnection.

## 0.3.15

- Kept recording, sending and read-aloud notices beside conversation controls while Mac setup is open.
- Showed connection-code errors beside the pairing input.
- Restored the selected conversation after discarding a recording.

## 0.3.12

- Remembered the read-aloud setting when reopening the app.
- Stopped treating old location measurements as fresh when phone updates stop.

## 0.3.4

- Choose a custom name for Hey voice activation in Operation settings.
- See your chosen name in conversation labels and reply status.
- Change or restore the name without restarting the app.
- Clearer default-name and microphone guidance, with unavailable-name messages while typing.
- Removed the redundant voice-ready message.
- Keep save-failure warnings visible while editing a name.

## 0.3.1

- Added optional Hey dot voice activation in English and Japanese.
- Added a Hey dot switch in Operation settings alongside hold-to-talk.
- Added automatic recording stop on silence, respecting automatic send.
- Added wake detection pause during read-aloud replies.
- Fixed recognition status remaining after no speech.
- Improved chat position retention when wake input ends without speech or is discarded.
- Improved Japanese wake-phrase removal from transcribed text.

## 0.3.0

- Added optional Hey dot voice activation, with English and Japanese pronunciation support.
- Added a listening prompt on G2 after the wake phrase is detected.
- Added automatic recording stop after a short silence, while respecting your automatic-send setting.
- Added a Hey dot switch in Operation settings; hold-to-talk remains available.
- Added automatic pause of wake detection during read-aloud replies.

## 0.2.38

- Fixed the latest conversation not appearing after a connection interruption during startup.
- Combined Mac setup, pairing, and device disconnection in one section.
- Added step-by-step Tailscale setup instructions for iPhone.
- Added a Copy URL button for the Mac download link, with success and failure messages.
- Improved pairing-code visibility and scrolling while using the iPhone keyboard.
- Fixed screen shifting after dismissing the keyboard and tapping the Mac download URL.
